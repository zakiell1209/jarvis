# Jarvis

Личный ИИ-агент (Capacitor + один файл `index.html`).

- `index.html` — само приложение (его правит агент через «Изменить приложение»)
- `shell.html` — оболочка: проверяет обновления на GitHub, применяет и откатывает (ИИ её не трогает)
- `.github/workflows/build.yml` — собирает APK и кладёт в Releases

Обновление интерфейса/функций приходит на телефон само («Доступно обновление → Обновить»).
Новый APK нужен только при смене нативной части (package.json, capacitor.config.json, shell.html).
